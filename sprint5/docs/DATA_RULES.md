# Правила заполнения карточки оборудования

| Поле | Обязательно | Правило |
|---|---|---|
| number | да | уникальный (без учёта регистра), рекомендуемый вид `INV-001` |
| type | да | ПК, монитор, принтер, проектор, маршрутизатор и т.п. |
| name | да | модель/наименование |
| room | да | номер кабинета (строка, например `101`) |
| state | да | только: `исправно`, `требует ремонта`, `списано` |
| received | нет | дата `ГГГГ-ММ-ДД` |
| responsible | нет | Ф.И.О. ответственного |

Лишние пробелы по краям обрезаются, состояние приводится к нижнему регистру.

## Корректные примеры
- `INV-013 | ПК | Acer Veriton | 101 | исправно | 2024-09-01 | Иванов И.И.`
- `INV-014 | принтер | Brother HL-1110 | 205 | требует ремонта | | ` (необязательные поля пусты)
- `  inv-015 | Монитор | LG 24 | 102 |  Исправно ` (пробелы и регистр нормализуются)

## Ошибочные примеры
| Запись | Причина | Сообщение |
|---|---|---|
| номер `INV-001` повторно | дубликат | «Запись с номером INV-001 уже существует.» |
| пустой кабинет | обязательное поле | «Поле «Кабинет» не должно быть пустым.» |
| состояние `сломано` | не из списка | «Недопустимое состояние. Допустимо: ...» |
| дата `01.09.2024` | неверный формат | «Дата поступления должна быть в формате ГГГГ-ММ-ДД ...» |
