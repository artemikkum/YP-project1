# Инструкция пользователя

## Запуск
В папке проекта выполните `python main.py`. Появится меню; выберите пункт, введя цифру и нажав Enter. Закрыть программу: пункт `0` (или Ctrl+D).

## Типовые задачи
**Узнать, где стоит компьютер.** Пункт 3 → 1 → введите номер, например `INV-006`. Покажется карточка с кабинетом.

**Что есть в кабинете.** Пункт 3 → 2 → номер кабинета (`101`).

**Что нужно чинить.** Пункт 6 → кабинет оставьте пустым → состояние `требует ремонта`.

**Принять новое оборудование.** Пункт 2. Номер можно не вводить - программа предложит следующий (`INV-013`). Дата и ответственный необязательны.

**Убрать дату или ответственного.** Пункт 4 → номер → на нужном поле введите `-`. Обязательные поля (тип, наименование, кабинет, состояние) очистить нельзя.

**Отметить, что отремонтировали.** Пункт 4 → номер → на вопросе «Состояние» введите `исправно`, остальные поля пропустите Enter.

**Списать/удалить.** Лучше изменить состояние на `списано` (запись остаётся в истории). Пункт 5 удаляет запись насовсем и требует ответа `да`.

## Сообщения программы
| Сообщение | Что делать |
|---|---|
| Не найдено | Проверьте номер/кабинет |
| Запись с номером ... уже существует | Введите другой номер или оставьте поле пустым |
| Поле «...» не должно быть пустым | Заполните обязательное поле |
| Недопустимое состояние | Введите одно из: исправно / требует ремонта / списано |
| ВНИМАНИЕ: Файл данных повреждён | Данные не потеряны: копия лежит рядом как `inventory.json.broken-...`. Откройте её в редакторе, исправьте JSON и верните имя `inventory.json` |

## Подсказки
- В пункте 4 клавиша Enter оставляет поле без изменений, `-` очищает необязательное поле.
- Если удалить запись с самым большим номером, этот номер выдастся следующей новой записи автоматически. Если это нежелательно - вводите номер вручную.

## Где хранятся данные
`data/inventory.json` - обычный текстовый файл. Его можно копировать как резервную копию.
