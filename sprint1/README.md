# Система учёта инвентаря компьютерных классов (спринт 1)

Консольное приложение на Python для учёта компьютерного оборудования колледжа.
**Проблема заказчика:** в колледже теряется информация об оборудовании - непонятно, где что стоит и в каком оно состоянии.

**Состояние проекта на конец спринта 1:** есть меню и просмотр оборудования на 12 демонстрационных записях. Добавление, поиск, изменение, удаление и хранение появятся в спринтах 2-4.

## Требования
Python 3.11+ (pytest - только для запуска тестов).

## Запуск
```bash
python main.py
```
Пункт `1` - показать оборудование, `0` - выход. Пункты 2-5 пока выводят сообщение о том, в каком спринте они будут реализованы.

## Тесты
```bash
python -m pytest
python -m unittest discover -s tests -t .
```

## Структура
```
main.py             меню
inventory.py        модель записи и вывод списка
data/inventory.json демонстрационные данные (12 записей)
tests/              автотесты
USER_STORIES.md     требования
```
